# hr-analytics-dashboard
Interactive HR Analytics Dashboard built using Power BI to analyse employee attrition, workforce demographics, and key HR metrics.

## Project Overview

This project is an interactive HR Analytics Dashboard developed using Power BI. The dashboard provides insights into employee attrition, workforce demographics, job roles, salary distribution, and other key HR metrics. It enables HR teams to identify trends that support better workforce planning and employee retention.

## Learning Note

This dashboard was created as part of a guided Power BI learning project inspired by an online tutorial. I used it to strengthen my understanding of data modelling, Power Query, DAX measures, and dashboard design. I can explain the data transformations, calculations, and visualisations used throughout the project.

## Business Problem

High employee attrition can increase recruitment costs and impact organisational performance. This dashboard helps HR teams monitor workforce trends, identify departments with higher attrition, and understand factors influencing employee turnover.

## Dataset

The dataset contains employee information, including:

- Employee ID
- Age
- Gender
- Department
- Job Role
- Education
- Salary
- Years at Company
- Attrition Status

## Tools Used

- Power BI
- Power Query
- DAX
- Microsoft Excel (CSV dataset)

## Dashboard Features

- Employee Overview
- Attrition Analysis
- Department-wise Attrition
- Job Role Analysis
- Age Distribution
- Salary Analysis
- Interactive Filters and Slicers

## Key KPIs

- Total Employees
- Attrition Count
- Attrition Rate
- Average Age
- Average Salary
- Average Years at Company

## Key Insights

- Certain departments experience higher attrition than others.
- Employees with fewer years at the company show higher turnover.
- Attrition varies across different job roles.
- Workforce demographics provide useful context for HR planning.

## Business Recommendations

- Focus retention efforts on departments with higher attrition.
- Develop employee engagement programmes for early-career employees.
- Monitor job roles with consistently high turnover.
- Use workforce analytics to support hiring and retention decisions.
